# Day Logger — умный планировщик временных блоков

Day Logger — это приложение для персонального учёта времени, построенное вокруг 30-минутных временных блоков. В отличие от обычных логгеров, которые лишь фиксируют прошлую активность, Day Logger анализирует исторические паттерны и генерирует контекстно-зависимые предсказания для будущих блоков, стремясь поддерживать сбалансированное распределение между работой, отдыхом, спортом и другими категориями.

**Живая демонстрация:** [https://planner-dutb.onrender.com](https://planner-dutb.onrender.com)

---

## Ключевые возможности

- **Сетка из 48 слотов на день** — Каждый день разделён на 48 получасовых слотов, представленных в виде прокручиваемой горизонтальной временной шкалы с навигацией колесом мыши.
- **Предсказания на основе ML** — Классификатор Random Forest (`scikit-learn`) предсказывает наиболее вероятную категорию для будущих блоков на основе дня недели, часа и предыдущего блока.
- **Оценка баланса дня** — Система вычисляет целевое распределение по недавней истории и оценивает текущий день по шкале 0–100, показывая, насколько он соответствует «золотой середине» пользователя.
- **Визуальная аналитика** — Четыре интерактивных графика (Chart.js) отображают распределение категорий, историю баланса, почасовую активность и паттерны по дням недели.
- **Система тем** — Четыре цветовые схемы (Midnight, Nord, Light, Matrix), сохраняемые в `localStorage`.
- **Удобство без лишних действий** — Один клик записывает блок; дополнительные поля вроде «уровня энергии» или «статуса» не требуются.
- **Активное окно** — Активными и используемыми в аналитике и предсказаниях считаются только часы с 08:00 до 24:00; ночное время (00:00–08:00) исключено, чтобы сон не классифицировался как отдых.

## Стек технологий

- **Бэкенд:** Python 3.11, FastAPI, SQLAlchemy 2.0, Pydantic
- **База данных:** SQLite (планируется миграция на PostgreSQL)
- **Фронтенд:** Vanilla JavaScript (ES6+), HTML5, CSS3 (CSS-переменные для тем), Chart.js
- **Машинное обучение:** scikit-learn (Random Forest), joblib
- **DevOps:** Docker, Render
- **Тестирование:** Pytest, HTTPX

## Архитектура и алгоритм предсказания

Конвейер предсказания состоит из двух слоёв:

1. **ML-модель** (`train_model.py`) — Классификатор Random Forest обучается на исторических блоках по трём признакам: день недели, час дня и закодированная категория предыдущего блока. Обученная модель и её label encoder сериализуются в `model.pkl`.

2. **Балансировка и ограничения** (`predictor.py`) — Во время инференса предсказанные моделью вероятности корректируются:
   - **штрафом за дефицит**, который препятствует чрезмерному представлению какой-либо категории относительно целевого распределения;
   - **правилом против повторов**, которое подавляет три одинаковых блока подряд;
   - **резервной эвристикой**, если файл модели недоступен.

Само целевое распределение выводится из активности за последние 14 дней, исключая ночные часы (00:00–08:00). Это гарантирует, что алгоритм учится только на активных периодах и не интерпретирует сон как «отдых».

## Локальная установка

### Требования

- Python 3.10+
- Git

### Шаги

    git clone https://github.com/GEAR-company-offical/planner.git
    cd planner
    python -m venv .venv

    # Windows:
    .\.venv\Scripts\Activate.ps1

    # macOS/Linux:
    source .venv/bin/activate

    pip install -r requirements.txt

**Опционально: сгенерировать реалистичные исторические данные**

    python seed_v2.py

**Обучить ML-модель**

    python train_model.py

**Запустить приложение**

    uvicorn app:app --reload

Приложение будет доступно по адресу `http://127.0.0.1:8000`.

## Обзор API

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/health` | Проверка работоспособности |
| GET | `/meta` | Категории и количество слотов |
| POST | `/blocks` | Создать временной блок |
| GET | `/blocks` | Список блоков (с фильтрацией) |
| GET | `/days/{date}` | Полная сетка дня (48 слотов) |
| PATCH | `/blocks/{id}` | Обновить блок |
| DELETE | `/blocks/{id}` | Удалить блок |
| GET | `/predict/{date}` | ML-предсказания для даты |
| GET | `/score/{date}` | Оценка баланса дня |
| GET | `/charts/{date}` | Данные для графиков (распределение, история) |
| GET | `/calendar/{date}` | Данные heatmap за 120 дней |
| GET | `/analytics/{date}` | Почасовая аналитика и аналитика по дням недели |
